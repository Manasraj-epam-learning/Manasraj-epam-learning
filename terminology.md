# Key Terminology

| Term | Definition |
|------|------------|
| Algorithm | A step-by-step procedure for solving a problem. |
| Model | The result of training: a mathematical function with learned parameters that maps inputs to outputs. |
| Dataset | A collection of examples used to train or evaluate a model. |
| Feature | An input variable used by the model (for example, hours studied). |
| Label / Target | The correct output the model should predict. |
| Training set | Data used to fit the model's parameters. |
| Validation set | Data used to compare models or tune hyperparameters. |
| Test set | Data held back for the final, unbiased evaluation. |
| Parameter | A value learned from data during training (weights, slope, intercept). |
| Hyperparameter | A setting chosen before training (learning rate, k, epochs). |
| Loss function | A formula measuring how wrong the model's predictions are. |
| Gradient descent | An optimisation method that adjusts parameters step by step to reduce the loss. |
| Epoch | One full pass through the training data. |
| Overfitting | Fitting noise in the training data so that performance on new data is poor. |
| Underfitting | A model too simple to learn the pattern; poor on both training and new data. |
| Classification | Predicting a category. |
| Regression | Predicting a continuous number. |
| Clustering | Grouping similar unlabelled items together. |
| Confusion matrix | A table of true/false positives and negatives. |
| Precision | Share of predicted positives that are truly positive. |
| Recall | Share of actual positives that the model found. |
| F1 score | Harmonic mean of precision and recall. |
| Bias (data) | Systematic skew in data that leads to unfair or inaccurate predictions. |
| Neural network | A model built from layers of connected units with learned weights. |
| Deep learning | Machine learning with neural networks that have many layers. |
| Transformer | A neural network architecture based on attention; the basis of most LLMs. |
| LLM | Large Language Model: a transformer trained on large text data to predict the next token. |
| Token | A unit of text (word or sub-word) processed by a language model. |
| Prompt | The input instruction or text given to a generative model. |
| Hallucination | A confident-sounding output that is false or unsupported. |
| Inference | Using a trained model to make predictions on new data. |
| Generative AI | Models that produce new content (text, images, audio, code). |
| Narrow AI | AI designed for a specific task; all current AI systems. |
| AGI | Artificial General Intelligence: hypothetical human-level AI across all tasks. |
